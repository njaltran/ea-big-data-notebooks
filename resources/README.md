## Thread

Three of the papers — [Banko & Brill](03-banko-brill-2001.md), [Halevy](04-halevy-unreasonable-effectiveness.md), and [Watson](05-watson-tutorial.md) — back one claim: **more data beats smarter algorithms, up to a point**. The course uses this to motivate the Big Data tech stack (Hadoop, Spark, NoSQL, stream processing, cloud) and the EA lens on top.

Each note has a companion reactive notebook under [`../notebooks/`](../notebooks/) — read the takeaway, then play with the notebook.
